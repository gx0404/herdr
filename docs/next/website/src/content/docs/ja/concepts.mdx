Herdr はターミナルワークスペースマネージャーです。実際のターミナルプロセスを動かし続け、その周りに構造を加えます。

## ワークスペース

ワークスペースは最上位のプロジェクトコンテナです。リポジトリ、タスク、調査ごとにひとつのワークスペースを使ってください。

ワークスペースはタブとペインを所有します。サイドバーの状態は内部のエージェントから集約されるので、どのプロジェクトが注意を必要としているかが分かります。

## セッションサイドバー

「セッション」パネルは、デスクトップのコーディングアプリと同じようにセッションを一覧表示します。パネルヘッダーには `✚`（新しいワークスペース）と `⌕`（セッションナビゲーターでセッションを検索）があります。その下の「エージェント概要」行は、オンラインのマシンのペイン内で入力待ち（`◆`）、失敗（`✕`）、実行中（スピナー）、完了してレビュー待ち（`●`）のエージェント数を表示し、クリックするとセッションナビゲーターが開きます。オフラインのキャッシュと External の項目は数に含めません。

既定ではワークスペースごとにグループ化されます。まずマシン行（ほかのマシンを追加したときだけ表示）、続いて各ワークスペースの折りたたみ矢印、名前、最も対応が必要な状態とそのエージェント数、ブランチと先行 / 遅延を示す薄い行があり、その下にペインごとに 1 行が並びます。エージェント行には状態グリフ、エージェント名、1 行の要約、経過時間が表示され、通常のターミナル行には `·` とペイン名またはディレクトリ名が表示されます。要約は、入力待ちのエージェントでは保留中の質問や権限リクエスト、失敗したエージェントではエラー、実行中のエージェントでは現在のツール（なければセッションタイトル）、それ以外ではセッションタイトルまたは最後のメッセージです。実行中の時間は現在のターン、それ以外は現在の状態になってからの時間です。時間は分単位に丸められ（`now`、`3m`、`1h`）、時間表示がある場合は時計の分が変わるとキャッシュ行を更新して 1 回の再描画を要求します。毎秒の再描画は行いません。linked worktree はメインのワークスペースの下に入れ子で表示され、メインのワークスペースを折りたたむと worktree も一緒に折りたたまれます。アクティブでサブエージェントやバックグラウンドタスクを持つエージェントには `▸2` タグが表示され、クリックするとアクティビティツリーが展開されます。外部ソースは最後に独自のグループとして続き、同じアクティビティ展開を使います。External の項目をクリックすると、server が `agent.activity.read` を告知している場合は読み取り専用のアクティビティを表示し、未告知ならサブエージェントページに利用不可と表示します。External の項目にはフォーカス先のペインがありません。ワークスペース行では、ドラッグによる並べ替え、数字キー、ナビゲーションモード、右クリックメニューを引き続き利用できます。

「ワークスペース別 ▾」をクリックするか、コマンドパレットで「セッションのグループ化を切り替え」を実行すると、状態別のグループ化に切り替わります。入力待ち、失敗、レビュー待ち、実行中、アイドル、Other（通常のターミナルや不明な状態）のセクションに分かれ、ペイン行には所属するワークスペースも表示されます。このビューでもアクティビティを展開でき、セクションの数はセッションだけを数え、子アクティビティは含めません。空のセクションは表示しません。この選択はマシンごとに記憶されます。フッターからは設定とヘルプを開くことができ、アクティブなマシンの状態も表示されます。マシンをクリックするとマシンを管理できます。ターミナルの幅が 100 列未満で、互換性のある左サイドバーがある場合は、パネルは 4 列のレールに縮小し、ワークスペースごとに番号付きの状態グリフが 1 つ表示されます。クリックするとそのワークスペースに切り替わります。カスタム、最大化、コンパクトのレイアウトはそれぞれ適切なジオメトリを維持します。

`prefix+a` を押すと、対応が必要な次のペインセッションへ移動します。入力待ちのエージェント、失敗したエージェント、レビュー待ちのエージェントの順に、ワークスペースとオンラインのマシンをまたいで循環します。External の項目とオフラインのキャッシュは対象外です。

クラシックレイアウト（旧 server を含む）とモバイル切り替えは、1 つのセッションツリーだけを使います。Inspector や重複した Agents 一覧はありません。クラシックのツリーはサイドバー全体の高さを使い、エージェント領域と分割しません。幅のドラッグ境界、折りたたみボタン、ワークスペースレール、スクロール、ワークスペースのナビゲーションは引き続き利用できます。旧内部セクションの境界は操作できません。既存の `sidebar_section_split` 設定は読み取れますが、新しい操作では分割比率を保存しません。設定したエージェント行、エージェント別の token、カスタム状態ラベル、選択したエージェントビュー、起動順は、このツリーのエージェントセッションに適用されます。起動順ではワークスペースのナビゲーションの下に 1 つの順序付きセッション一覧を表示し、異なるマシンの起動番号を比較しません。ワークスペース別では、複数のタブがあるワークスペースにタブごとの折りたたみヘッダーを表示します。矢印はそのタブのセッションだけを隠し、名前をクリックするとタブにフォーカスします。エージェントのナビゲーションはビュー計算で対象セッション（レールではワークスペース）を表示位置まで移動し、折りたたんだ祖先を展開します。External 行は報告されたエージェント名と必要な読み取り不可の表示を保ちます。アクティビティタグは件数全体を表示するか名前を優先して隠し、数字を途中で切りません。ワークスペース、セッション、アクティビティ行には 1 つの比例スクロールバーを使います。

## タブ

タブはワークスペース内のレイアウトです。`agents`、`logs`、`server`、`review` のようにビューを分けるために使います。

タブは CLI とソケット API からアドレス指定できます。

## ペイン

ペインは実際のターミナルです。Herdr はターミナル出力を描画し、入力をプロセスに送り返し、クライアントのデタッチ後もペインを維持します。

ペインは右または下に分割できます。手動での名前変更、CLI からの読み取り、入力の送信、クローズができます。

ペインは既定色の問い合わせに必ず応答します。`OSC 10 ; ?`、`OSC 11 ; ?`、`OSC 12 ; ?` で前景色・背景色・カーソル色を問い合わせるプログラムは、Herdr がホストターミナルのテーマを取得する前でも応答を受け取れます。フォールバックは色ごとです。ホストターミナルが報告していない色だけが Herdr 自身のターミナル既定色にフォールバックするため、ホストが背景色だけを報告した場合、ペインの前景色は Herdr の既定色を報告し続けます。プログラムがカーソル色を設定していない場合、カーソル色は前景色に従います。Herdr 自身の既定色はホストの外観に従います。ホストがライト外観を報告した場合は白地に黒、それ以外は黒地に白です。そのため `OSC 11` から配色を決めるプログラムが、ライトなターミナルでダークテーマを選んでしまうことはありません。応答には問い合わせと同じ終端子（`BEL` または `ST`）を使います。

ペインが実際の既定色を持つようになったため、反転表示（`CSI ? 5 h`）は前景色と背景色を実際に入れ替えてペインを明示的に描画するようになり、無視されなくなりました。ペインの色が Herdr の与えた既定色と一致している限り、ペインは引き続きホストの背景色を継承します。

## マウス UI

Herdr はマウスネイティブです。ペイン、タブ、ワークスペース、エージェントをクリックできます。分割境界のドラッグ、テキスト選択、右クリックメニューも使えます。以下で説明する操作はすべてマウスでも行えます。キーボードバインドは任意のレイヤーです。

キーボードのみで操作したい場合や、Herdr にマウス入力をキャプチャさせたくない場合は、マウスキャプチャを無効にしてください:

```toml
[ui]
mouse_capture = false
```

ドッキングレイアウトでは、パネルタイトルの `⠿` ハンドルをドラッグしてパネルを並べ替えます。**Lock layout** がオンのあいだはパネルタイトルに `⠿` ハンドルが表示されず、ステータスバーはレイアウトがロックされていることと、タイトルバーの `⋯` メニューで解除できることを示し、**Arrange layout** のサイズ変更と移動のヒントは淡色表示になります。最大化したパネルは画面上の唯一のパネルなので、ドッキング先がありません。タイトルに `⠿` ハンドルは表示されず、タイトルを押してもそのパネルにフォーカスが移るだけで、ステータスバーはレイアウトを元に戻す方法を示します（`◫` をクリック。マウスキャプチャが無効なときは **Arrange layout** で `Enter`）。レイアウトのロック中でも元に戻せ、そのときステータスバーはロック中であることも示します。**Arrange layout** モードでは、枠線のないペインの `⠿` ハンドルはペインのすぐ上の行（タブが並ぶパネルヘッダーまたはペイン間のすき間）に表示され、端末の 1 行目を覆いません。その行に空きがない場合にかぎり、ペインの 1 行目に表示されます。マウスキャプチャを無効にすると（`mouse_capture = false`）何もドラッグできないため、パネルタイトルとペインに `⠿` ハンドルは表示されず、ステータスバーはメインメニューの **Arrange layout** とそのキー（`Tab` でパネルを選択、矢印でサイズ変更、`Shift+矢印` で移動）を示します。レイアウトのロック中は、タイトルバーの `⋯` メニューではなくメインメニューで **Lock layout** をオフにするよう案内します。

端末がドッキングレイアウトの最小サイズより小さいと、Herdr はフォーカス中のパネルだけを表示するコンパクトビューに切り替わります。各パネルには最小の幅と高さがあるため、Inspector を隠した既定のレイアウトには 37 列・7 行が、ターミナルの横に Monitor パネルをドッキングすると 66 列が必要です。コンパクトビューのパネルヘッダーにはレイアウト順にすべてのパネルが並び、現在のパネルが強調表示されます。名前をクリックするとそのパネルに切り替わり、**Arrange layout** で `Tab` を押しても切り替えられます。名前が収まらないときは、パネルヘッダーにはフォーカス中のパネルだけが表示されます。コンパクトビューはドッキング先のパネルが 1 つしかないため、パネルヘッダーに `⠿` ハンドルは表示されず、どこを押してもフォーカスを切り替えるだけでドラッグは始まりません。`ui.mouse_capture = false` のときは名前クリックでの切り替えができないため、ステータスバーは **Arrange layout** + `Tab` のヒントのままになります。ドッキングレイアウトは `ui.mobile_width_threshold` とモバイルのスイッチャーを使いません。これらは古いサーバーに接続したときのクラシックレイアウトでのみ有効です。

## エージェント

エージェントは、Herdr がペイン内で認識するプロセスです。Herdr はフォアグラウンドプロセス、スクリーンマニフェスト、任意のインテグレーションからエージェントを検出します。

エージェントの状態は次のとおりです:

| 状態 | 意味 |
| --- | --- |
| `blocked` | エージェントが入力、承認、または判断を必要としている。 |
| `working` | エージェントが実行中。 |
| `done` | エージェントが完了し、まだ確認されていない。 |
| `idle` | エージェントが完了または待機していて、確認済み。 |
| `unknown` | Herdr が状態を確信を持って分類できない。 |

各クライアントは表示した完了を独立して管理します。あるクライアントで完了を見ても、ほかのクライアントの Done バッジは消えません。CLI/API はサーバーの既読状態を使うため、特定のクライアントのバッジと一致するとは限りません。`idle` と `done` はどちらも入力可能な状態です。

ドッキング、クラシック、モバイルのエージェントセッションは同じセッションツリーを使います。アクティビティを展開すると、Claude Code の workflow → phase → サブエージェントのように、実行中の部分とその祖先を表示します。workflow と phase は `⧉` と `▤`（狭い行では `W` と `P`）と実行中/合計の件数を表示します。灰色の完了行は完了・失敗をまとめ、クリックでサブエージェントページを開きます。`+N more` は実行中の要約が省略された場合だけ表示します。

エージェントセッションの右クリックで **Focus**、**View agent activity**（報告された活動がなければ淡色表示）、**Rename pane**、**Close pane** を選べます。名前変更はマシンを切り替えずにペインを所有するマシンへ送信し、オフラインや `pane.rename` 非対応では無効です。リモート操作が拒否されると理由を通知します。リモートの worktree グループを閉じる場合は、そのマシンに切り替えて確認するよう案内します。ワークスペースのヘッダーはコンテキストメニューを維持し、External の項目は読み取り専用のままです。

### エージェント概要

`prefix+g` でエージェント概要を開きます。状態グループはゼロでない件数だけを表示し、最初はグループごとに 6 セッションを表示します。見出しや **more** 行で Enter を押すと展開します。`g` は場所別モードへ切り替え、マシン、ワークスペース、端末のナビゲーションを維持します。Space は受信した洞察のプレビューを切り替えます。既読/未読と手動マークはこのクライアント専用で、サーバーの状態ではありません。返信の機能と ID 規則は[エージェント](/ja/docs/agents/)を参照してください。

### Inspector

ドッキングレイアウトは **Sessions | Terminal | Inspector** を使用し、区切り列を除いた幅の比率は 20 / 56 / 24 です。バージョン 1 のレイアウトは一度だけバージョン 2 に移行します。旧 Agents と廃止済み Accounts を除き、ルートの右端に Inspector を挿入して、ターミナルの分割ツリーとグループ、フォーカス、ロック、有効な最大化を保持します。一度だけアップグレードを通知します。壊れたレイアウトは従来どおりリセットし、将来のバージョンは移行しません。

Inspector はフォーカス中のエージェントのタイトル、状態、ターン時間、接続先/ワークスペース/ブランチ/タブ、モデル、質問と選択肢または失敗理由、最後のメッセージとプロンプト、サブエージェントの概要、直近 8 件のローカル状態遷移を表示します。通常のターミナルは明確な空状態を表示し、洞察や活動読み取りのない旧サーバーも利用できます。Codex はセッションフックが有効なスレッド ID を報告すると活動を読み取れます。ID がなければ `not_implemented` を返す場合があります。ローカルの状態遷移履歴は最大 128 エージェントを保持し、接続先、サーバー boot、ペイン、エージェントの起動 ID で分離します。サーバーの監査ログではありません。

**サブエージェント N** セクションは完全な活動ツリーに代わり、**入力待ち**、**失敗**、**実行中**、**完了**、**待機** の件数を 0 以外だけ表示します。代表項目は最大 3 行で、入力待ち、失敗、実行中を優先します。最後の **すべて表示 ›** 行には `d` の案内を表示します。ショートカットはキーキャップ形式で、`↵` **移動して回答**、`d` **サブエージェントページ**、`r` **更新** を表示します。

Inspector は既定で非表示です。`prefix+i` で表示と非表示を切り替え、client-shell の設定に接続先ごとに保存します。保存済みの接続先ごとの選択は引き続き有効です。手動で保存した `inspector_visibility` の値 `auto` は、140 列以上で Inspector を表示する動作を保ちます。切り替えキーは `auto` を保存しません。サイズ変更でドックのツリーを書き換えません。表示中は既存の `agent.activity.read` で一度に 1 件だけ、サイドバーの実行中の要約だけでなく報告された完全なツリーを読み、最大毎秒 1 回追従します。オーバーレイを開いている間は、新しい追従読み取りを停止します。非表示や対象変更でローカルの追従を止めますが、サーバーが受理済みの読み取りは完了する場合があり、追従のリースは期限切れになります。ツリーキャッシュは最大 8 対象、対象ごとに 512 ノードと 128 KiB の表示テキストで、対象のツリーが大きすぎると省略の通知を表示します。ノード出力とページ読み取りはサブエージェントページで行います。時間表示は分単位で更新し、作業中の記号は同じアニメーションクロックを共有します。

### サブエージェントページ

サブエージェントページは、エージェントのサブエージェント、タスク、ToDo、バックグラウンドプロセスを表示します。Inspector の **サブエージェントページ**、**すべて表示 ›**、または Inspector にキーボードフォーカスがあるときの `d` で開きます。従来のセッションのアクティビティ項目、完了行、`+N more`、External の項目、右クリックメニューの **View agent activity** からも開けます。アクティビティ項目から開くとその項目を選択します。ワークベンチレイアウトではコンテンツ領域を使い、クラシックとモバイルでは画面全体を使います。

ヘッダーには **戻る**、**サブエージェント**、所有者と場所を表示し、右側に **追従**、**更新**、**ターミナルへ移動**、**閉じる** を配置します。外部ソースは **読み取り専用** と表示し、移動先のターミナルはありません。活動読み取りに対応しない旧サーバーでは、ツリーの代わりに説明を表示します。Codex はセッションフックが有効なスレッド ID を報告すると活動を読み取れます。それまでは `agent.activity.read` が `not_implemented` を返す場合があります。

`1`、`2`、`3` でビューを切り替えます。Herdr は現在のセッション中、その選択を記憶します:

| キー | ビュー | 内容 |
| --- | --- | --- |
| `1` | 階層 | 親子関係のツリー |
| `2` | 状態 | 状態別のグループ |
| `3` | タイムライン | 上にスイムレーン、下にトランスクリプトと概要。120 列未満では概要を非表示 |

Codex、Claude Code、OpenCode のトランスクリプトは、引用、アシスタント本文、思考、ツール呼び出しと出力、プラン、メタ情報の階層ブロックに分けて表示します。ツール出力は折りたためます。長い行は折り返し、トランスクリプトの最新部分だけを表示する場合は注記を出します。

所有者がペインの場合は追従モードで開き、およそ 1 秒ごとに更新します。上にスクロールするまで出力は最新行に留まります。一番下に戻るか、トランスクリプトで `End` を押すと新しい出力への追従を再開します。`f` は追従を切り替え、`r` はツリーと選択したトランスクリプトを更新します。外部の項目は読み取り専用で、定期的には追従しません。

100 列未満では 1 列表示、60 列未満では各項目を 1 行で表示します。80 列未満ではヘッダーのボタンをアイコンだけにします。高さが 12 行未満ではヘッダーの 2 行目を隠し、幅が 40 列未満または高さが 8 行未満では最小限の案内だけを表示します。

| キー | 動作 |
| --- | --- |
| `↑` `↓` / `j` `k` | フォーカスに応じて項目を選択、またはトランスクリプトをスクロール |
| `←` `→` / `h` `l` | 項目を折りたたむ / 展開する |
| `Tab` | 一覧とトランスクリプトの間でフォーカスを切り替える |
| `Enter` | 一覧では選択したトランスクリプトを開く。トランスクリプトではすべてのツール出力を展開 / 折りたたむ |
| `/` | 一致する項目の祖先を残して絞り込む |
| `c` | 完了した項目を折りたたむ / 展開する |
| `f` | 追従を切り替える |
| `r` | 更新 |
| `t` | 所有者のターミナルへ移動。所有者がペインの場合のみ |
| `PgUp` `PgDn` `Home` `End` | フォーカスのある領域をスクロール / ジャンプ |
| `Esc` | まず絞り込みを解除し、それ以外はページを閉じる |

マウスで行、ビューのタブ、ボタンを選択でき、ツールの見出しをクリックすると出力の折りたたみを切り替えます。ホイールはポインターのある領域をスクロールします。

## セッション

セッションは永続的な Herdr サーバーの名前空間です。デフォルトの `herdr` コマンドはデフォルトセッションにアタッチします。

名前付きセッションは独立したランタイム名前空間です:

```bash
herdr session list
herdr session attach work
herdr session attach side-project
```

まずはワークスペースを使ってください。ペイン、ソケット、永続化されたランタイム状態を完全に分離する必要があるときに名前付きセッションを使います。

## クライアントとサーバー

デフォルトでは、Herdr はバックグラウンドサーバーと、それにアタッチした 1 つ以上のクライアントとして動作します。

サーバーはペインとプロセス状態を所有します。クライアントはそのサーバーにアタッチしたターミナル UI です。

クライアントが 1 つだけ接続されている場合、従来どおりすべてのタブがそのサイズに従います。複数のクライアントが接続されている場合、それぞれ別のワークスペースやタブを表示できます。異なるタブはそれぞれを表示するクライアントのサイズに従い、同じタブを表示している場合は、最後にそのタブへフォーカス、選択、または操作したクライアントがペインのサイズを制御します。

`ctrl+b q` でクライアントをデタッチします。サーバーとエージェントは動き続けます。

セッションを終了してそのペインを停止したい場合は、サーバーを停止します:

```bash
herdr server stop
```

## モード

Herdr にはターミナルモード、プレフィックスモード、ナビゲートモードがあります。

ターミナルモードはフォーカス中のペインにキーを送ります。プレフィックスモードはプレフィックスキーの後に Herdr のアクションをひとつ待ちます。ナビゲートモードは常駐のワークスペースナビゲーション画面です。

プレフィックスキー (デフォルト `ctrl+b`) を押してから、新しいタブなら `c`、ワークスペースナビゲーションなら `w` のようにアクションキーを押します。プレフィックスの考え方が初めてなら[キーボード](/ja/docs/keyboard/)を参照してください。
