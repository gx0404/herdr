Herdr はターミナルワークスペースマネージャーです。実際のターミナルプロセスを動かし続け、その周りに構造を加えます。

## ワークスペース

ワークスペースは最上位のプロジェクトコンテナです。リポジトリ、タスク、調査ごとにひとつのワークスペースを使ってください。

ワークスペースはタブとペインを所有します。サイドバーの状態は内部のエージェントから集約されるので、どのプロジェクトが注意を必要としているかが分かります。

## タブ

タブはワークスペース内のレイアウトです。`agents`、`logs`、`server`、`review` のようにビューを分けるために使います。

タブは CLI とソケット API からアドレス指定できます。

## ペイン

ペインは実際のターミナルです。Herdr はターミナル出力を描画し、入力をプロセスに送り返し、クライアントのデタッチ後もペインを維持します。

ペインは右または下に分割できます。手動での名前変更、CLI からの読み取り、入力の送信、クローズができます。

ペインは既定色の問い合わせに必ず応答します。`OSC 10 ; ?`、`OSC 11 ; ?`、`OSC 12 ; ?` で前景色・背景色・カーソル色を問い合わせるプログラムは、Herdr がホストターミナルのテーマを取得する前でも応答を受け取れます。フォールバックは色ごとです。ホストターミナルが報告していない色だけが Herdr 自身のターミナル既定色にフォールバックするため、ホストが背景色だけを報告した場合、ペインの前景色は Herdr の既定色を報告し続けます。プログラムがカーソル色を設定していない場合、カーソル色は前景色に従います。Herdr 自身の既定色はホストの外観に従います。ホストがライト外観を報告した場合は白地に黒、それ以外は黒地に白です。そのため `OSC 11` から配色を決めるプログラムが、ライトなターミナルでダークテーマを選んでしまうことはありません。応答には問い合わせと同じ終端子（`BEL` または `ST`）を使います。

ペインが実際の既定色を持つようになったため、反転表示（`CSI ? 5 h`）は前景色と背景色を実際に入れ替えてペインを明示的に描画するようになり、無視されなくなりました。ペインの色が Herdr の与えた既定色と一致している限り、ペインは引き続きホストの背景色を継承します。

## マウス UI

Herdr はマウスネイティブです。ペイン、タブ、ワークスペース、エージェントをクリックできます。分割境界のドラッグ、テキスト選択、右クリックメニューも使えます。以下で説明する操作はすべてマウスでも行えます。キーボードバインドは任意のレイヤーです。

キーボードのみで操作したい場合や、Herdr にマウス入力をキャプチャさせたくない場合は、マウスキャプチャを無効にしてください:

```toml
[ui]
mouse_capture = false
```

ドッキングレイアウトでは、パネルタイトルの `⠿` ハンドルをドラッグしてパネルを並べ替えます。**Lock layout** がオンのあいだはパネルタイトルに `⠿` ハンドルが表示されず、フッターはドラッグを促す代わりにレイアウトがロックされていることを示し、**Arrange layout** のサイズ変更と移動のヒントは淡色表示になります。最大化したパネルは画面上の唯一のパネルなので、ドッキング先がありません。タイトルに `⠿` ハンドルは表示されず、タイトルを押してもそのパネルにフォーカスが移るだけで、フッターはレイアウトを元に戻す方法を示します（`◫` をクリック。マウスキャプチャが無効なときは **Arrange layout** で `Enter`）。レイアウトのロック中でも元に戻せ、そのときフッターはロック中であることも示します。**Arrange layout** モードでは、枠線のないペインの `⠿` ハンドルはペインのすぐ上の行（タブバーまたはペイン間のすき間）に表示され、端末の 1 行目を覆いません。その行に空きがない場合にかぎり、ペインの 1 行目に表示されます。マウスキャプチャを無効にすると（`mouse_capture = false`）何もドラッグできないため、パネルタイトルとペインに `⠿` ハンドルは表示されず、フッターはドラッグを促す代わりにメインメニューの **Arrange layout** とそのキー（`Tab` でパネルを選択、矢印でサイズ変更、`Shift+矢印` で移動）を示します。レイアウトのロック中は、上部バーではなくメインメニューで **Lock layout** をオフにするよう案内します。

端末がドッキングレイアウトの最小サイズより小さいと、Herdr はフォーカス中のパネルだけを表示するコンパクトビューに切り替わります。各パネルには最小の幅と高さがあるため、既定のレイアウトには 37 列・13 行が、ターミナルの横に Monitor パネルをドッキングすると 66 列が必要です。コンパクトビューのタイトルバーにはレイアウト順にすべてのパネルが並び、現在のパネルが強調表示されます。名前をクリックするとそのパネルに切り替わり、**Arrange layout** で `Tab` を押しても切り替えられます。名前が収まらないときは、タイトルバーにはフォーカス中のパネルだけが表示されます。コンパクトビューはドッキング先のパネルが 1 つしかないため、タイトルバーに `⠿` ハンドルは表示されず、どこを押してもフォーカスを切り替えるだけでドラッグは始まりません。`ui.mouse_capture = false` のときは名前クリックでの切り替えができないため、フッターは **Arrange layout** + `Tab` のヒントのままになります。ドッキングレイアウトは `ui.mobile_width_threshold` とモバイルのスイッチャーを使いません。これらは古いサーバーに接続したときのクラシックレイアウトでのみ有効です。

## エージェント

エージェントは、Herdr がペイン内で認識するプロセスです。Herdr はフォアグラウンドプロセス、スクリーンマニフェスト、任意のインテグレーションからエージェントを検出します。

エージェントの状態は次のとおりです:

| 状態 | 意味 |
| --- | --- |
| `blocked` | エージェントが入力、承認、または判断を必要としている。 |
| `working` | エージェントが実行中。 |
| `done` | エージェントが完了し、まだ確認されていない。 |
| `idle` | エージェントが完了または待機していて、確認済み。 |
| `unknown` | Herdr が状態を確信を持って分類できない。 |

各クライアントは表示した完了を独立して管理します。あるクライアントで完了を見ても、ほかのクライアントの Done バッジは消えません。CLI/API はサーバーの既読状態を使うため、特定のクライアントのバッジと一致するとは限りません。`idle` と `done` はどちらも入力可能な状態です。

Agents パネルは、エージェントを折りたたみ可能なツリーで表示します。マシン（ほかのマシンを追加しているときだけ。ワークスペース一覧と同じです）→ ワークスペース → タブ（そのワークスペースにタブが複数あるときだけ）→ エージェントの順です。ワークスペースとタブのヘッダーは配下のエージェントの状態を集約し、マシンのヘッダーはそのマシンの接続状態を示し、どのヘッダーにも含まれる項目の数が表示されます。ヘッダーのどこをクリックしても折りたたみ・展開できます。ブロック中のエージェントの状態テキストは状態色の太字になります。ブロック中と作業中が同じ `●` になる既定のドットアイコンでは、ブロック中のエージェントを含むワークスペースやタブのヘッダーの数の前に太字の `!` が付き、状態テキストが収まらないブロック中の行には代わりに太字の `!` が表示されるので、色だけに頼らず見分けられます。ここでマシンを折りたたむと、ワークスペース一覧の同じマシンも折りたたまれます。各エージェント行には状態アイコン、名前、幅に余裕があれば状態テキストが表示され、エージェントがサブエージェントやタスクを報告しているときはアクティビティバッジも付きます。実行中のものがあれば `2/5 running`（実行中 / 合計）、すべて終わっていれば `5 activities`（1 件なら `1 activity`）のように合計だけを表示し、アクティビティがなければバッジは付きません。バッジはその行の 1 行目の文字を優先します。完全なバッジを付けると 1 行目の文字（ツリーではエージェント名、起動順などのフラットな表示ではワークスペース名）が短く切れてしまうときは、バッジはまず `2/5` のような数字だけに縮み、サイドバーがさらに狭いと表示されなくなります。状態アイコンとその文字の表示が常に優先されます。行の矢印で最新のアクティビティ 1 件を展開でき、ほかにもあるときは `+N more` の行が続きます。どちらかをクリックするとエージェントアクティビティウィンドウが開きます。エージェント行を右クリックすると、**Focus**、**View agent activity**（エージェントがアクティビティを報告していないときは淡色表示）、**Rename pane**（エージェントが動いているマシン上のペイン名を、そのマシンに切り替えずに変更します。そのマシンがオフラインのあいだ、またはその server が `pane.rename` を告知していないときは淡色表示）、**Usage** と **Bind account**（Herdr がアカウント使用量を追跡する Codex、Claude Code、Kimi Code、OpenCode、Pi のみ）、**Close pane** を選べます。ほかのマシンが名前の変更やペインを閉じる操作を拒否したとき（ペインがすでに閉じているなど）は、理由を通知で表示します。閉じるとそのマシンの worktree グループも閉じる場合は、そのマシンに切り替えてから閉じて確認するよう通知で案内します。ワークスペースのヘッダーを右クリックすると、ワークスペース一覧でそのワークスペースを右クリックしたときと同じメニューが開きます。並べ替えトグルはこのツリーと起動順を切り替えます。起動順ではエージェントを起動順にフラットに並べますが、エージェント行は引き続きアクティビティを展開できます。複数のマシンに接続している場合、起動順はまずマシンごとにグループ化し、各マシン内で起動順に並べます。マシンをまたいで起動順を混在させることはありません。状態で絞り込んだビューもフラットで、External の項目は表示されません。エージェントが 1 つもなく状態の絞り込みもないときは、一覧は空白のままにならず、中央に `no agents` と表示されます。パネルが低すぎてグループのヘッダーを表示できないときは、代わりにすべてのエージェントをワークスペース名付きでフラットに並べます（1 行しか入らないときは、その行に状態アイコン、エージェント名、ワークスペース名の順に表示します）。クラシックレイアウトの折りたたんだサイドバーにもすべてのエージェントが表示されます。これらのフラットな一覧には展開するためのヘッダーがないため、ワークスペース・タブ・External グループを折りたたんでいても項目は隠れません。例外は折りたたんだマシンです。ほかのマシンを追加していてパネルがツリー表示（起動順や状態の絞り込みではない）のときは、マシンを折りたたむとそのエージェントもこれらのフラットな一覧から外れ、ワークスペース一覧でそのマシンを展開すると戻ります。折りたたんだサイドバーに表示されるのは Herdr のペインで動いているエージェントだけで、External の項目は展開したパネルにだけ表示されます。エージェントが収まりきらないときは、折りたたんだサイドバーのエージェント一覧をマウスホイールでスクロールできます。`keys.previous_agent` / `keys.next_agent` でエージェントを切り替えると、切り替え先のエージェントが見える位置までスクロールします。Herdr のペインの外で外部ソースが報告するエージェントは、ソースごとの External グループに表示され、クリックするとそのエージェントアクティビティウィンドウが開きます。古いサーバーに接続したときのクラシックレイアウトでは、モバイルのスイッチャーはフラットなエージェント一覧のまま、エージェントの詳細の後に同じアクティビティバッジを表示します。行に収まらないときは、バッジは同じくまず数字だけに縮み、さらに収まらなければ表示されません。数字が途中で切れることはありません。

### エージェントアクティビティウィンドウ

エージェントアクティビティウィンドウは、エージェントが報告するサブエージェント、タスク、ToDo、バックグラウンドプロセスを表示します。Agents パネルでエージェント行の下にあるアクティビティ項目（または `+N more`）をクリックする、External グループの項目をクリックする、またはエージェント行（アクティビティがあるとき）や External の項目の右クリックメニューで **View agent activity** を選ぶと開きます。アクティビティ項目から開いた場合は、その項目が選択された状態になります。

左の列はアクティビティツリーです。各項目にはツリー上の枝、状態マーク、ラベル、種類、実行時間が表示されます。実行中の項目はアクセントカラー、失敗した項目は赤、完了した項目はグレーです。項目の矢印をクリックすると子項目を折りたたんだり展開したりできます。右の列には選択した項目の出力が表示され、その上の見出し行に項目のラベル、種類、状態、時間と、ソースが報告していればタイプと概要が並びます。見出し行に収まらないときは、まず状態の文字を省き（状態マークは残ります）、次にラベルを短くし、さらに種類、最後に時間を省きます。時間が数字の途中で切れることはありません。Markdown の出力は見出しとリスト記号に色が付き、JSON Lines の出力は 1 レコードを 1 行で、`type`、`role`、`name` を先頭に付けて表示します。長い行は列の幅で折り返され、出力の最新部分だけを表示しているときは上部に注記が出ます。

ペイン内のエージェントでは、ウィンドウは追従モードで開きます。Herdr はおよそ 1 秒ごとにツリーを更新し、更新のたびに新しい出力を読み込みます。上にスクロールするまで出力は最新行に留まります。一番下まで戻るか、出力にフォーカスがあるときに `End` を押すと、再び新しい出力に追従します。追従は **Follow** ボタンか `f` でオフにできます。オフの間にエージェントのアクティビティが変わるとタイトルに注記が出て、**Refresh** ボタンか `r` でツリーと選択中の出力を読み直します。外部ソースの項目には「External source, read-only」と表示され、追従しません。こうした項目の注記はソースが定期的に返す一覧に基づきますが、大きな項目では一覧にツリーの一部しか載らないことがあります。一覧が読み込んだツリーと一致するまでは注記が出ないため、変化を確かめたいときは `r` を押してください。エージェントや項目の名前が長いときはタイトル側を短くするので、この表示と更新の注記は隠れずに残ります。マシンとの接続が切れるなどして読み込みが中断された場合は、マシンに再び接続できるようになった時点でウィンドウが読み込みをやり直します。

このウィンドウはフローティングページです。上の枠をドラッグすると移動し、左右と下の枠をドラッグするとサイズを変えられます（**Lock layout** がオンのあいだはドラッグできません）。位置とサイズは Herdr が記憶します。エージェントアクティビティを提供しないサーバー（古い Herdr サーバーなど）では、ツリーの代わりに注記が表示されます。枠の内側が 60 列より狭いときは一度に 1 列だけを表示し、`Tab` でツリーと出力を切り替えます。

| キー | 動作 |
| --- | --- |
| `↑` `↓` | 前後の項目を選択。出力にフォーカスがあるときは出力をスクロール |
| `←` `→` | 選択中の項目を折りたたむ / 展開する。子項目で `←` を押すと親項目を選択し、出力で押すとフォーカスをツリーに戻す |
| `Enter` | 選択中の項目の出力を最初から読み直し、フォーカスを出力に移す |
| `Tab` | ツリーと出力の間でフォーカスを切り替える |
| `PgUp` `PgDn` `Home` `End` | フォーカスのある列をスクロール / ジャンプ |
| `f` | 追従のオン / オフ |
| `r` | 更新 |
| `Esc` | ウィンドウを閉じる。ほかのウィンドウから開いた場合はそのウィンドウに戻る |

マウスホイールはポインターがある列をスクロールし、ウィンドウの外をクリックすると閉じます。

## セッション

セッションは永続的な Herdr サーバーの名前空間です。デフォルトの `herdr` コマンドはデフォルトセッションにアタッチします。

名前付きセッションは独立したランタイム名前空間です:

```bash
herdr session list
herdr session attach work
herdr session attach side-project
```

まずはワークスペースを使ってください。ペイン、ソケット、永続化されたランタイム状態を完全に分離する必要があるときに名前付きセッションを使います。

## クライアントとサーバー

デフォルトでは、Herdr はバックグラウンドサーバーと、それにアタッチした 1 つ以上のクライアントとして動作します。

サーバーはペインとプロセス状態を所有します。クライアントはそのサーバーにアタッチしたターミナル UI です。

クライアントが 1 つだけ接続されている場合、従来どおりすべてのタブがそのサイズに従います。複数のクライアントが接続されている場合、それぞれ別のワークスペースやタブを表示できます。異なるタブはそれぞれを表示するクライアントのサイズに従い、同じタブを表示している場合は、最後にそのタブへフォーカス、選択、または操作したクライアントがペインのサイズを制御します。

`ctrl+b q` でクライアントをデタッチします。サーバーとエージェントは動き続けます。

セッションを終了してそのペインを停止したい場合は、サーバーを停止します:

```bash
herdr server stop
```

## モード

Herdr にはターミナルモード、プレフィックスモード、ナビゲートモードがあります。

ターミナルモードはフォーカス中のペインにキーを送ります。プレフィックスモードはプレフィックスキーの後に Herdr のアクションをひとつ待ちます。ナビゲートモードは常駐のワークスペースナビゲーション画面です。

プレフィックスキー (デフォルト `ctrl+b`) を押してから、新しいタブなら `c`、ワークスペースナビゲーションなら `w` のようにアクションキーを押します。プレフィックスの考え方が初めてなら[キーボード](/ja/docs/keyboard/)を参照してください。
