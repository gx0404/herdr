Herdr 是一个终端工作区管理器。它让真实的终端进程持续运行,并在其之上添加结构。

## 工作区

工作区是最顶层的项目容器。为每个仓库、任务或调查使用一个工作区。

工作区拥有标签页和窗格。它在侧边栏中的状态由内部的智能体汇总而来,让你一眼看出哪个项目需要关注。

## 标签页

标签页是工作区内的一种布局。用标签页来分隔不同视图,比如 `agents`、`logs`、`server` 或 `review`。

标签页可以通过 CLI 和 socket API 寻址。

## 窗格

窗格是一个真实的终端。Herdr 渲染终端输出,把输入传回进程,并在客户端分离后保留窗格。

窗格可以向右或向下分割。它们可以手动重命名、通过 CLI 读取、接收输入,以及被关闭。

窗格始终会回答默认颜色查询。用 `OSC 10 ; ?`、`OSC 11 ; ?` 或 `OSC 12 ; ?` 查询前景色、背景色或光标色的程序,在 Herdr 还没拿到宿主终端主题时也能收到回复。回落是逐色的:宿主终端没有上报的那一项才回落到 Herdr 自身的终端默认色,所以宿主只上报了背景色时,窗格的前景色仍然上报 Herdr 的默认色。程序没有设置光标色时,光标色跟随前景色。Herdr 自身的默认色跟随宿主外观:宿主上报浅色外观时用白底黑字,否则用黑底白字。因此按 `OSC 11` 选配色的程序不会在浅色终端里选成深色主题。回复使用与查询相同的终止符(`BEL` 或 `ST`)。

由于窗格现在真的有了默认色,反色显示(`CSI ? 5 h`)会真正交换前景色与背景色并显式绘制窗格,而不再被忽略。只要窗格的颜色仍等于 Herdr 给它的默认色,窗格就继续继承宿主背景。

## 鼠标 UI

Herdr 是鼠标原生的。你可以点击窗格、标签页、工作区和智能体,可以拖动分割边框、选择文本、使用右键菜单。下文的所有操作都可以用鼠标完成;按键绑定是可选的一层。

如果你偏好纯键盘操作,或者不想让 Herdr 捕获鼠标输入,可以禁用鼠标捕获:

```toml
[ui]
mouse_capture = false
```

## 智能体

智能体是 Herdr 在窗格内识别出的进程。Herdr 通过前台进程、屏幕清单和可选的集成来检测智能体。

智能体状态如下:

| 状态 | 含义 |
| --- | --- |
| `blocked` | 智能体需要输入、审批或决策。 |
| `working` | 智能体正在运行。 |
| `done` | 智能体已完成,你还没有查看。 |
| `idle` | 智能体已完成或在等待,并且已被查看过。 |
| `unknown` | Herdr 无法有把握地判断状态。 |

每个客户端独立记录它已显示的完成状态。在一个客户端查看完成状态，不会清除其他客户端的 Done 标记。CLI/API 使用服务器的已查看状态，因此不一定与某个客户端的标记相同；`idle` 和 `done` 都表示可以接受输入。

Agents 面板把 agent 组织成一棵可折叠的树：机器（仅连接了多台机器时出现）→ 工作区 → 标签页（仅该工作区有不止一个标签页时出现）→ agent。分组头行汇总状态与 agent 数量，点击头行任意位置即可折叠或展开；在这里折叠某台机器，工作区列表里的同一台机器也会一起折叠。每个 agent 行显示状态图标、名称、放得下时的状态文字，agent 报告了子 agent 或任务时还有活动徽标：仍有运行中的写 `运行中 2/5`（运行中 / 总数），都已结束时只写总数，例如 `5 个活动`（只有 1 个时写 `1 个活动`），没有活动则不显示徽标。侧栏较窄时徽标先缩成只剩数字（如 `2/5`），再窄就不显示，始终优先保住状态图标和名称。点该行的箭头会展开最新的一项活动，还有更多时跟一行 `还有 N 项`；点击其中任一行打开「Agent 活动」窗口。右键 agent 行可选择：聚焦、查看活动、重命名窗格、绑定账号、关闭窗格。排序切换在这棵树与启动顺序之间切换：启动顺序按启动先后平铺 agent，agent 行仍可展开活动。有多台机器时，启动顺序先按机器分组，组内再按启动序排列；不会跨机器混排启动序。按状态筛选的视图同样平铺。既没有任何 agent 也没有状态筛选时，列表区正中显示「暂无 agent」，不再是一片空白。面板矮到放不下分组头时，改为平铺列出全部 agent 并带上工作区名（只放得下一行时，这一行依次是状态图标、agent 名与工作区名）；折叠的侧栏同样列出全部 agent。这两种平铺列表里没有分组头可以展开，所以折叠的工作区、标签页与「外部」分组不会把其中的条目藏起来。折叠的机器是例外：连接了多台机器且面板显示的是树（不是启动顺序或状态筛选）时，折叠某台机器也会把它的 agent 从这两种平铺列表里拿掉，在工作区列表里展开该机器即可恢复。折叠的侧栏只列 Herdr 窗格里的 agent，「外部」条目只在展开的面板里出现。外部来源在 Herdr 窗格之外报告的 agent 按来源归入「外部」分组，点击即可打开它的「Agent 活动」窗口。移动端切换器保持平铺的 agent 列表，并在 agent 详情之后显示同样的活动徽标；这一行放不下时，徽标同样先缩成只剩数字，再放不下就不显示，不会把数字截掉一半。

### Agent 活动窗口

Agent 活动窗口展示 agent 上报的子 agent、任务、待办与后台进程。打开方式：在 Agents 面板里点击 agent 行下的活动项（或「还有 N 项」），点击「外部」分组里的条目，或在 agent 行的右键菜单里选择 **查看 Agent 活动**。从活动项打开时会直接选中这一项。

左列是活动树，每一项显示它在树里的连接线、状态标记、标签、种类与已运行时长：运行中用强调色，失败为红色，已完成为灰色。点击某项前的箭头可折叠或展开它的子项。右列显示所选项的输出，顶部头行是该项的标签、种类、状态与时长，来源提供时还会显示它的类型与摘要。头行放不下时，先省去状态文字（状态标记仍在），再缩短标签，然后依次省去种类与时长；时长要么完整显示，要么不显示，不会只剩半截数字。Markdown 输出会给标题与列表记号着色；JSON Lines 输出每条记录一行，并以其 `type`、`role`、`name` 作前缀。长行按列宽折行；只显示输出的最新部分时，顶部会有提示。

对窗格里的 agent，窗口以跟随模式打开：Herdr 大约每秒刷新一次活动树，每次刷新后读取新输出，输出停在最新一行，直到你向上滚动。滚回底部或按 `End` 即可重新跟住新输出。用 **跟随** 按钮或 `f` 关闭跟随；关闭期间 agent 的活动有变化时，标题旁会出现提示，**刷新** 按钮或 `r` 会重新读取活动树与所选输出。外部来源的条目标有「外部来源，只读」，不会跟随。agent 或条目的名称很长时，标题会缩短名称，让这个标记与更新提示始终可见。读取被打断时（例如与机器的连接断开），窗口会在机器恢复连接后重新读取。

窗口是浮动页面：拖动上边框移动，拖动左右与下边框调整大小，Herdr 会记住它的位置与尺寸。不提供 Agent 活动的 server（例如较旧的 Herdr server）会显示提示而不是活动树。窗口边框内窄于 60 列时一次只显示一列，用 `Tab` 在活动树与输出之间切换。

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` | 选择上一项或下一项；焦点在输出时滚动输出 |
| `←` `→` | 折叠或展开所选项；在子项上按 `←` 选中其父项，在输出里按 `←` 把焦点交回活动树 |
| `Enter` | 从头重新读取所选项的输出，并把焦点移到输出 |
| `Tab` | 在活动树与输出之间切换焦点 |
| `PgUp` `PgDn` `Home` `End` | 在焦点所在列里滚动或跳转 |
| `f` | 开启或关闭跟随 |
| `r` | 刷新 |
| `Esc` | 关闭窗口；若是从其他窗口打开的，回到那个窗口 |

鼠标滚轮滚动指针所在的那一列；在窗口外点击即关闭窗口。

## 会话

会话是一个持久的 Herdr 服务器命名空间。默认的 `herdr` 命令连接到默认会话。

命名会话是彼此独立的运行时命名空间:

```bash
herdr session list
herdr session attach work
herdr session attach side-project
```

优先使用工作区。当你需要完全独立的窗格、socket 和持久化运行时状态时,才使用命名会话。

## 客户端与服务器

默认情况下,Herdr 以一个后台服务器加一个或多个已连接客户端的方式运行。

服务器拥有窗格和进程状态。客户端是连接到该服务器的终端 UI。

只有一个客户端连接时,所有标签页会像以前一样采用该客户端的尺寸。连接多个客户端时,每个客户端都可以查看自己的工作区和标签页。不同标签页会分别采用查看它们的客户端尺寸;客户端查看同一标签页时,最后聚焦、选择或操作该标签页的客户端控制其中窗格的尺寸。

用 `ctrl+b q` 分离客户端。服务器和智能体会继续运行。

如果想结束会话并停止其中的窗格,停止服务器:

```bash
herdr server stop
```

## 模式

Herdr 有终端模式、前缀模式和导航模式。

终端模式把按键发送给聚焦的窗格。前缀模式在按下前缀键后等待一个 Herdr 动作。导航模式是常驻的工作区导航界面。

按下前缀键 (默认 `ctrl+b`),再按一个动作键,比如 `c` 新建标签页,`w` 打开工作区导航。第一次接触前缀键的概念?参见[键盘](/zh-cn/docs/keyboard/)。
