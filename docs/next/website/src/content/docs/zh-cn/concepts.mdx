Herdr 是一个终端工作区管理器。它让真实的终端进程持续运行,并在其之上添加结构。

## 工作区

工作区是最顶层的项目容器。为每个仓库、任务或调查使用一个工作区。

工作区拥有标签页和窗格。它在侧边栏中的状态由内部的智能体汇总而来,让你一眼看出哪个项目需要关注。

## 会话侧栏

「会话」面板像桌面端编程应用一样列出你的会话。面板头有 `✚`（新建工作区）和 `⌕`（在会话导航里搜索会话）。下面的「智能体总览」一行统计在线机器的窗格内需要输入（`◆`）、失败（`✕`）、运行中（转圈）和已完成待查看（`●`）的智能体数量，点击它打开会话导航。离线缓存的智能体与「外部」条目不计入数量。

默认按工作区分组：先是机器行（只在添加了其它机器时出现），然后是每个工作区——折叠箭头、名称、最需要你处理的状态及其中的智能体数，一行暗色的分支与领先 / 落后信息，再往下每个窗格一行。智能体行显示状态字形、智能体名称、单行摘要和时长；普通终端行显示 `·` 和窗格名或目录名。摘要的取法：需要输入时是待回答的问题或权限请求，失败时是错误，运行中是当前工具（没有就用会话标题），其余情况是会话标题或最后一条消息。运行中的时长计算当前回合，其余状态计算进入当前状态的时间。时长按分钟取整（`now`、`3m`、`1h`）：有时长时，墙钟跨分钟会刷新缓存行并请求一次重绘，不逐秒重绘。linked worktree 嵌套在主工作区下面，折叠主工作区会一并收起它的 worktree。活跃且有子代理或后台任务的智能体会显示 `▸2` 标签，点击即可展开活动树。外部来源单独成组排在最后，复用同样的活动展开。点击外部条目时，若 server 宣告了 `agent.activity.read`，可查看只读活动；没有宣告时子智能体页面会说明不可用。外部条目没有可聚焦的窗格。工作区行仍然支持拖动排序、数字键跳转、导航模式和右键菜单。

点击「按工作区 ▾」，或在命令面板里执行「切换会话分组」，可以改为按状态分组：需要输入、失败、待查看、运行中、空闲，以及「其它」（普通终端或未知状态）几个分区，窗格行同时标出所在工作区。这个视图仍可展开活动，分区数量只统计会话，不包含活动子项；空分区不显示。这个选择按机器记住。页脚可以打开设置和帮助，并显示当前机器的状态，点击机器即可管理机器。终端窄于 100 列且停靠布局有兼容的左侧栏时，面板收成 4 列的图标栏，每个工作区一格编号加状态字形，点击即可切换过去。自定义、最大化和紧凑布局保留各自适用的几何。

按 `prefix+a` 跳到下一个需要你处理的窗格会话：先是需要输入的智能体，然后是失败的，再是等待查看的，在各个工作区和在线机器之间循环。外部条目和离线缓存的智能体不参与。

经典布局（包括旧版 server）与移动端切换器只使用一棵「会话」树，没有 Inspector，也没有第二份 Agents 列表。经典会话树使用整个侧栏高度，不再与智能体分区平分。宽度拖动边框、折叠按钮、工作区图标栏、滚动和工作区导航仍然可用；内部旧分区分隔线不再可拖动。已有的 `sidebar_section_split` 偏好仍可读取，但新交互不再保存分区比例。配置的智能体行、各家 token、自定义状态标签、选中的智能体视图及启动排序均用于这棵树中的智能体会话。启动排序在工作区导航下方显示一份有序会话列表，不跨机器比较各自的启动序。按工作区分组时，多标签页工作区会显示每个标签页的可折叠头行：箭头只隐藏该标签页的会话，点击名称聚焦标签页。智能体导航在视图计算时揭示目标会话（图标栏中则揭示工作区），并展开折叠的祖先。外部条目保留上报的智能体名称及适用的不可读标记；活动标签完整显示计数，或让位于名称，不截断数字。工作区、会话及活动行共用一个比例滚动条。

## 标签页

标签页是工作区内的一种布局。用标签页来分隔不同视图,比如 `agents`、`logs`、`server` 或 `review`。

标签页可以通过 CLI 和 socket API 寻址。

## 窗格

窗格是一个真实的终端。Herdr 渲染终端输出,把输入传回进程,并在客户端分离后保留窗格。

窗格可以向右或向下分割。它们可以手动重命名、通过 CLI 读取、接收输入,以及被关闭。

窗格始终会回答默认颜色查询。用 `OSC 10 ; ?`、`OSC 11 ; ?` 或 `OSC 12 ; ?` 查询前景色、背景色或光标色的程序,在 Herdr 还没拿到宿主终端主题时也能收到回复。回落是逐色的:宿主终端没有上报的那一项才回落到 Herdr 自身的终端默认色,所以宿主只上报了背景色时,窗格的前景色仍然上报 Herdr 的默认色。程序没有设置光标色时,光标色跟随前景色。Herdr 自身的默认色跟随宿主外观:宿主上报浅色外观时用白底黑字,否则用黑底白字。因此按 `OSC 11` 选配色的程序不会在浅色终端里选成深色主题。回复使用与查询相同的终止符(`BEL` 或 `ST`)。

由于窗格现在真的有了默认色,反色显示(`CSI ? 5 h`)会真正交换前景色与背景色并显式绘制窗格,而不再被忽略。只要窗格的颜色仍等于 Herdr 给它的默认色,窗格就继续继承宿主背景。

## 鼠标 UI

Herdr 是鼠标原生的。你可以点击窗格、标签页、工作区和智能体,可以拖动分割边框、选择文本、使用右键菜单。下文的所有操作都可以用鼠标完成;按键绑定是可选的一层。

如果你偏好纯键盘操作,或者不想让 Herdr 捕获鼠标输入,可以禁用鼠标捕获:

```toml
[ui]
mouse_capture = false
```

停靠布局下拖动面板标题的 `⠿` 把手即可重新排布。开启「锁定布局」后，面板标题不再显示 `⠿` 把手，状态栏说明布局已锁定、可在标题栏 `⋯` 菜单解除，「调整布局」模式里调尺寸与移动两条提示也会置灰。最大化的面板是画面上唯一的面板，没有可停靠的位置：它的标题不画 `⠿` 把手，按下标题只切换焦点，状态栏改为说明怎么还原布局——点 `◫`（不接鼠标时在「调整布局」模式按 `Enter`）。布局锁定时同样可以还原，状态栏会同时注明布局已锁定。「调整布局」模式下，无边框窗格的 `⠿` 把手画在窗格正上方那一行（带标签的面板头或窗格间的空隙），不再压住终端首行；只有那一行没有空位时才留在窗格首行。关闭鼠标捕获（`mouse_capture = false`）后什么都拖不动：面板标题与窗格不再显示 `⠿` 把手，状态栏改为指向主菜单里的「调整布局」及其键位——`Tab` 切换面板、方向键调尺寸、`Shift+方向键` 移动；布局锁定时则说明到主菜单（而不是标题栏的 `⋯` 菜单）取消「锁定布局」。

终端小于停靠布局的最小尺寸时，Herdr 改用只显示聚焦面板的「紧凑视图」。每个面板都有最小宽高，所以 Inspector 隐藏时默认布局需要 37 列、7 行，终端旁停靠了监控面板后需要 66 列。紧凑视图的面板头按布局顺序列出全部面板并高亮当前面板：点面板名即可切过去，也可以进「调整布局」按 `Tab`。面板名放不下时面板头只显示聚焦面板。紧凑视图只有一个面板可停靠，面板头不画 `⠿` 把手，按下面板头任意位置只切换焦点，不会开始拖动。`ui.mouse_capture = false` 时点名字切换用不了鼠标，状态栏保留「调整布局」+ `Tab` 提示。停靠布局不使用 `ui.mobile_width_threshold` 与移动端切换器，二者只在连接旧版 server 时的经典布局下生效。

## 智能体

智能体是 Herdr 在窗格内识别出的进程。Herdr 通过前台进程、屏幕清单和可选的集成来检测智能体。

智能体状态如下:

| 状态 | 含义 |
| --- | --- |
| `blocked` | 智能体需要输入、审批或决策。 |
| `working` | 智能体正在运行。 |
| `done` | 智能体已完成,你还没有查看。 |
| `idle` | 智能体已完成或在等待,并且已被查看过。 |
| `unknown` | Herdr 无法有把握地判断状态。 |

每个客户端独立记录它已显示的完成状态。在一个客户端查看完成状态，不会清除其他客户端的 Done 标记。CLI/API 使用服务器的已查看状态，因此不一定与某个客户端的标记相同；`idle` 和 `done` 都表示可以接受输入。

停靠、经典与移动端布局中的智能体会话共用同一棵会话树。展开活动时显示活跃子树及其祖先，例如 Claude Code 的 workflow → phase → 子 agent。workflow 与 phase 分组用 `⧉`、`▤`（窄行降级为 `W`、`P`），并显示运行中/总数。灰色完成行汇总完成与失败的活动，点击可打开子智能体页面；只有活跃摘要被截断时才出现「还有 N 项」。

右键智能体会话可选择 **聚焦**、**查看 Agent 活动**（没有上报活动时置灰）、**重命名窗格**及**关闭窗格**。重命名直接作用于窗格所属机器，无需切换；离线或不支持 `pane.rename` 时置灰。远程操作被拒绝时提示原因；关闭远程 worktree 分组时要求切到该机器确认。工作区头行保留工作区右键菜单；外部条目仍为只读。

### 智能体总览

`prefix+g` 打开智能体总览。状态分组只显示非零计数，每组初始保留六个会话；在组头或「更多」行按 Enter 展开。`g` 切换位置模式，保留机器、工作区与终端导航。Space 切换所选智能体的已收到洞察预览。已读/未读徽标和手动标记只属于本客户端，不是服务端事实。回复能力与身份规则参见[智能体](/zh-cn/docs/agents/)。

### Inspector

停靠布局使用 **会话 | 终端 | Inspector**，扣除分隔列后的内容宽度比例为 20 / 56 / 24。版本 1 布局只迁移一次到版本 2：移除旧 Agents 与已退役 Accounts 面板，把 Inspector 插到根节点右侧，保留终端分割树与分组、焦点、锁定及合法最大化。升级后提示一次；损坏布局仍复位，未来版本不迁移。

Inspector 显示聚焦智能体的标题、状态、轮次时长、端点/工作区/分支/标签页、模型、问题与选项或失败原因、最近消息与提示、子智能体摘要，以及最近八条本地观察的状态转移。普通终端显示明确空状态；旧服务端没有洞察或活动读取能力时仍可使用。Codex 会话钩子上报可用线程 ID 后支持活动读取，缺少该 ID 时才可能返回 `not_implemented`。本地状态转移历史最多缓存 128 个智能体，并按端点、服务端 boot、窗格和智能体启动身份隔离，不是服务端审计日志。

**子智能体 N** 小节取代整棵活动树。计数行按 **需要输入**、**失败**、**运行中**、**已完成**、**等待** 排列，只列非零项。最多显示三行代表条目，优先需要输入、失败、运行中；末行是 **查看全部 ›**，并提示 `d`。快捷操作使用键帽样式：`↵` **跳转到终端**（有待回答的问题时为 **跳转并回答**）、`d` **子智能体页面**、`r` **刷新活动**。

Inspector 默认隐藏。`prefix+i` 在显示与隐藏之间切换，并按端点保存到 client-shell 偏好。已有的按端点选择保持生效。手工保存的 `inspector_visibility` 值 `auto` 仍表示达到 140 列时显示 Inspector；切换键不会保存 `auto`。调整尺寸不会改写停靠树。可见 Inspector 用现有 `agent.activity.read` 方法单飞读取来源报告的完整树，而不只是侧栏中的活跃摘要，最多每秒跟随一次。弹层打开时暂停发起新的跟随读取。隐藏或切换目标会在本地停止跟随；已被服务端接受的读取仍可能完成，其跟随租约会到期。活动缓存最多八个目标，每个目标 512 个节点和 128 KiB 显示文本；单树超限时显示截断提示。节点输出与分页仍在子智能体页面中。时长与相对时间按分钟刷新，工作中字形共享同一个动画时钟。

### 子智能体页面

子智能体页面展示智能体的子 agent、任务、待办与后台进程。在 Inspector 中点击 **子智能体页面**、**查看全部 ›**，或在 Inspector 获得键盘焦点时按 `d` 打开。原有的会话活动项、完成摘要、「还有 N 项」、「外部」条目和右键菜单的 **查看 Agent 活动** 也会打开此页面；从活动项打开时直接选中该项。工作台布局下页面占据内容区，经典与移动布局下占满整屏。

页头显示 **‹ 返回**、**子智能体**、属主与位置；右侧依次是跟随开关（**跟随中** 或 **已暂停**）、**刷新**、**跳到终端** 和关闭按钮 **×**。外部来源标记为 **外部来源，只读**，没有跟随开关，也没有可跳转的终端。旧服务端不支持活动读取时显示说明而不是活动树。Codex 会话钩子上报可用线程 ID 后即可读取活动；在此之前，`agent.activity.read` 可能返回 `not_implemented`。

按 `1`、`2`、`3` 切换视图，Herdr 在本次会话中记住选择：

| 按键 | 视图 | 内容 |
| --- | --- | --- |
| `1` | 层级 | 按父子关系展示的树 |
| `2` | 状态 | 按状态分组 |
| `3` | 时间线 | 上方泳道，下方转写与概要；不足 120 列时隐藏概要 |

Codex、Claude Code 和 OpenCode 的转写解析为分层区块：引用、助手正文、思考、工具调用及输出、计划与元信息。工具输出可折叠。长行会折行；仅显示转写的最新部分时会给出提示。

属主为窗格时，页面默认跟随，大约每秒刷新一次。输出保持在最新一行，直到向上滚动；回到底部或在转写中按 `End` 即可重新跟随新输出。`f` 切换跟随，`r` 刷新活动树与所选转写。暂停跟随期间，智能体的活动有变化时页头会显示 **有更新，按 r 刷新**。外部条目保持只读，不周期跟随。

不足 100 列时使用单栏，不足 60 列时每项只占一行；不足 80 列时页头按钮只显示图标。高度不足 12 行时隐藏页头第二行；宽度不足 40 列或高度不足 8 行时，只显示最小提示。

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` / `j` `k` | 按焦点选择条目或滚动转写 |
| `←` `→` / `h` `l` | 折叠或展开条目 |
| `Tab` | 在列表与转写之间切换焦点 |
| `Enter` | 在列表中打开所选转写；在转写中展开或收起全部工具输出 |
| `/` | 筛选条目，保留匹配项的祖先节点 |
| `c` | 收起或展开已完成条目 |
| `f` | 切换跟随 |
| `r` | 刷新 |
| `t` | 跳到属主终端，仅属主为窗格时可用 |
| `PgUp` `PgDn` `Home` `End` | 在焦点区域滚动或跳转 |
| `Esc` | 先清除筛选，否则关闭页面 |

鼠标可点击行、视图标签和按钮；点击工具头可切换其输出的折叠状态。滚轮滚动指针所在区域。

## 会话

会话是一个持久的 Herdr 服务器命名空间。默认的 `herdr` 命令连接到默认会话。

命名会话是彼此独立的运行时命名空间:

```bash
herdr session list
herdr session attach work
herdr session attach side-project
```

优先使用工作区。当你需要完全独立的窗格、socket 和持久化运行时状态时,才使用命名会话。

## 客户端与服务器

默认情况下,Herdr 以一个后台服务器加一个或多个已连接客户端的方式运行。

服务器拥有窗格和进程状态。客户端是连接到该服务器的终端 UI。

只有一个客户端连接时,所有标签页会像以前一样采用该客户端的尺寸。连接多个客户端时,每个客户端都可以查看自己的工作区和标签页。不同标签页会分别采用查看它们的客户端尺寸;客户端查看同一标签页时,最后聚焦、选择或操作该标签页的客户端控制其中窗格的尺寸。

用 `ctrl+b q` 分离客户端。服务器和智能体会继续运行。

如果想结束会话并停止其中的窗格,停止服务器:

```bash
herdr server stop
```

## 模式

Herdr 有终端模式、前缀模式和导航模式。

终端模式把按键发送给聚焦的窗格。前缀模式在按下前缀键后等待一个 Herdr 动作。导航模式是常驻的工作区导航界面。

按下前缀键 (默认 `ctrl+b`),再按一个动作键,比如 `c` 新建标签页,`w` 打开工作区导航。第一次接触前缀键的概念?参见[键盘](/zh-cn/docs/keyboard/)。
