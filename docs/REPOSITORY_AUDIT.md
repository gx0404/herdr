### 测试覆盖变化

没有删除业务回归断言。精确迁移清单与原因见 `.config/test-suites.toml`：已知真实
集成二进制、少量大数据/deadline 资格、发布环境演练与长重试窗口移入完整集；新测试默认纳入。
普通单测线程运行以减少启动开销，进程资源数量和初始 ID 断言仍在默认集单独隔离。
完整集使用 nextest，为这些约束保留逐测试进程基线。

Hook 决策矩阵逐条调用真实 JSON/参数/配置入口，复用 Python 解释器；原样注册命令、
Bash 包装与 Codex 协议适配仍跑真实子进程。决策断言不删减，优化只减少重复进程启动。

试跑发现的两项共享进程限制已通过显式隔离分类处理，不改其断言。现有测试中裸
`python3` 在 Windows 可能触发安装管理器，已改为当前解释器。既有 setup 入口对传入
`--` 的命令行转发限制另记待修问题，本轮测试入口通过自身脚本传递参数，不依赖该路径。

默认集通过不证明真实 SSH/PTY/安装升级或任意 CLI 版本兼容；需要这些证据时执行
`just test-full` 和对应专项入口。默认目标 60 秒与完整验收分别出账，实际结果以本轮
manifest/log 为准。Linux/macOS 与真实桌面客户端未本地运行的项目保持 PENDING。

完整集复测发现 Windows 发布演练夹具向原生子进程传入 Bash 风格 TMP/TEMP，
偶发产生额外临时目录警告。夹具改为保留带盘符的项目内路径，原始 stderr 字节断言不变。

图谱诊断没有缺失端点、悬空关系或重复边，但有 3 条 AST 导入自环：harness/json、
harness/time、remote/process 与同名外部导入的解析发生合并。这是当前钉版提取器的
关系解析局限，保留原始生成数据与诊断，不手工删除边；涉及这些关系时回到源码核验。
